# Student Management System

A beginner-friendly student record management app built with HTML, CSS and JavaScript.

## Features
- Register a student with name, matric number, email, department, level and phone number.
- View the student list.
- Search by name, matric number, email, department or level.
- Edit existing student information.
- Delete student records after a confirmation prompt.
- Save records in the browser using `localStorage`.

## How to run
1. Download and extract the ZIP file.
2. Open `index.html` in a web browser.
3. Use the form to add students. The records remain saved in that browser.

## Files
- `index.html` — page structure
- `style.css` — layout and design
- `script.js` — registration, search, update, delete and local storage logic

## Note
This is a front-end demonstration project. It stores data in the current browser on the device; it does not use an online database or user login.
